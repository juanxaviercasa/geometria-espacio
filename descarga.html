Descargar el proyecto completo

El botón arma un archivo .zip con todos los archivos del sitio —páginas, estilos, lógica, la dependencia Three.js y la documentación— listo para subirlo a GitHub. El paquete se construye en tu navegador, leyendo los archivos de este mismo sitio: no se envía nada a ningún servidor.

Pulsa el botón para leer los archivos y generar el paquete.

Qué incluye el paquete

El listado se rellena al generar el ZIP: verás el tamaño de cada archivo leído. Si alguno no se pudiera leer, aparecería marcado en rojo con el motivo, en lugar de entregarte un paquete incompleto sin avisar.

Qué hacer con el ZIP

  1. Descomprímelo. Obtendrás una carpeta con los .html en la raíz y las carpetas css/, js/ y vendor/.
  2. Para verlo funcionando sin subirlo, abre index.html con doble clic. Algunas cosas (la vista 3D por módulos ES) pueden requerir un servidor local; el resto del sitio funciona igual.
  3. Para publicarlo en GitHub, sigue SUBIR-A-GITHUB.md, que va incluido dentro del ZIP y explica la subida por web, la subida por terminal y la activación de GitHub Pages.
Importante: la carpeta vendor/ no es opcional. Contiene three.module.min.js (392 KB, licencia MIT), la única ruta 3D del proyecto. Si se excluye al subir, todas las figuras pasan a la vista 2D.
