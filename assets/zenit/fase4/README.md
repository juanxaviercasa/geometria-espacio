# Imágenes cinematográficas · Zénit Aurora

Esta carpeta recibe los 8 recursos originales de la actualización visual HD de la portada.

Para activarlos, sube **los ocho WebP y el archivo `catalog.json`**, con sus nombres originales, a esta carpeta en `main`. La portada ya incluye el cargador `js/zenit-hd-assets.js`, que reemplaza automáticamente las imágenes de respaldo cuando encuentra `catalog.json` con `"ready": true`.

| Archivo | Sección | Formato |
|---|---|---|
| aprender.webp | Aprender mirando | 4:3 |
| experimentar.webp | Experimentar cambiando | 4:3 |
| resolver.webp | Resolver con sentido | 4:3 |
| ruta.webp | Tu ruta para conquistar la geometría | 16:9 |
| entender.webp | Entender antes que memorizar | 4:3 |
| error.webp | Un error puede mostrarte el camino | 4:3 |
| verificar.webp | Comprobar te da seguridad | 4:3 |
| cierre.webp | CTA final | 16:9 |

Los WebP (aprox. 1.3 MB en total) fueron optimizados desde las imágenes hiperrealistas originales de la conversación. Hasta que se incorporen, la portada mantiene imágenes locales de respaldo sin recursos rotos.
